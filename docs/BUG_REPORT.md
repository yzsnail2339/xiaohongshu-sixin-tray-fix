# Windows 私信通 1.0.11：关闭主窗口后托盘无法恢复

## 现象与复现

1. 启动 Windows 版小红书私信通 1.0.11。
2. 点击主窗口右上角 ×。
3. 程序仍在后台，窗口从任务栏消失。
4. 点击或双击托盘图标，原窗口无法恢复。

期望：点击托盘图标恢复既有窗口、任务栏图标和焦点；不会要求通过再启动一个客户端实例来打开新窗口。

登录页窗口即可用于复现与验证，不必提交账号或私信数据。

## 原因定位

- `main/windows.js` 的 `close` 处理调用 `preventDefault()`、`hide()`、`setSkipTaskbar(true)`。
- `main/tray/tray.js` 的原版 `click` 回调只停止托盘闪烁，没有 `show()` 或窗口恢复调用；没有注册 `double-click` 恢复事件。
- 原托盘窗口菜单项带有 `submenu`，同时在父项绑定恢复回调。该组合的实际行为未单独验证；明确增加子菜单入口更易操作和测试。

原包故障已在真实源码的模拟 Electron 回归测试中复现；本地修复后由 Windows 用户确认托盘恢复成功。

## 建议修复

统一恢复函数：跳过已销毁窗口和退出中状态，执行 `setSkipTaskbar(false)`；若已最小化先 `restore()`，再 `show()`、`focus()`。

托盘单击和双击调用统一恢复函数，并保留停止图标闪烁的行为。在每个窗口的右键子菜单增加明确的“显示窗口”，保留原有“退出窗口”。重复点击不创建新窗口。

本地补丁只修改两个脚本，其余 1,806 个归档文件内容经校验保持一致。不涉及登录、私信、网络请求或安全设置。
